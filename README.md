# Laborator 4 – Python

Acest proiect conține rezolvarea celor două cerințe ale Laboratorului 4.

## Cerința 1 – Conjectura lui Goldbach

Fișier: `goldbach.py`

Programul citește un număr natural par mai mare decât 2 și afișează toate perechile distincte de numere prime a căror sumă este numărul introdus.

Exemplu pentru 10:
- 10 = 3 + 7
- 10 = 5 + 5

## Cerința 2 – Adunarea și înmulțirea numerelor mari

Fișier: `numere_mari.py`

Programul citește două numere naturale din `numere.txt`, fiecare pe câte un rând. Numerele pot avea maximum 200 de cifre.

Adunarea și înmulțirea se realizează cifră cu cifră, fără transformarea numerelor întregi în tipul `int`.

Exemplu pentru 999 și 2:
- Suma: 1001
- Produsul: 1998

## Rularea programelor

Programele necesită Python 3.

1. Deschideți proiectul în Visual Studio Code.
2. Pentru prima cerință, rulați `goldbach.py` și introduceți un număr par mai mare decât 2.
3. Pentru a doua cerință, introduceți două numere în `numere.txt`, fiecare pe câte un rând.
4. Rulați `numere_mari.py` pentru a afișa suma și produsul.
