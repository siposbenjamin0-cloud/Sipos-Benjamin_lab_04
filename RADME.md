# Laborator 4 - Python

Acest proiect contine rezolvarile Laboratorului 4.

## Cerinta 1 - Conjectura lui Goldbach
Programul afiseaza toate perechile distincte de numere prime a caror suma este numarul par introdus.

## Cerinta 2 - Numere mari
Programul aduna si inmulteste doua numere naturale de cel mult 200 de cifre, fara conversia numerelor intregi la tipul int.
